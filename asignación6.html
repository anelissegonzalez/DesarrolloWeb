Introducción al Desarrollo Web

Este curso trata sobre los fundamentos básicos para aprender a crear sitios web. Aquí aprenderemos a estructurar páginas usando solamente etiquetas HTML, comprendiendo cómo se organiza la información en el navegador.

¿Qué es una página web?

Una página web es un documento digital que contiene información como textos, imágenes, videos y enlaces. Está escrita en un lenguaje que las computadoras y los navegadores pueden entender fácilmente.


¿Cómo funcionan?

Funcionan mediante un proceso de petición y respuesta. Nosotros, desde nuestra computadora (el cliente), escribimos una dirección. Esa solicitud viaja por internet hasta otra computadora (el servidor), la cual nos devuelve los archivos de la página para que el navegador los muestre en pantalla.


Tipos de páginas web

Existen principalmente páginas estáticas y dinámicas. Las estáticas siempre muestran el mismo contenido a todos los usuarios, mientras que las dinámicas cambian su información en tiempo real dependiendo de la base de datos o lo que haga el usuario.


Diferencia entre una aplicación web y un sitio web

La diferencia principal está en la interactividad. Un sitio web se usa principalmente para leer o consumir información (como una página de noticias). En cambio, una aplicación web permite al usuario realizar acciones complejas, como crear cuentas, hacer compras o enviar mensajes (como Facebook o la banca en línea).


Resumen de Tipos de Páginas

Tipo de Página Web Descripción Ejemplo
